## 🗓️ Month-by-Month Plan

### **MONTH 1-2: Foundation Building** (Current)

#### Technical Skills
- [ ] Choose your **primary tech stack** (Frontend/Backend/Full-Stack/Mobile/Data Science)
- [ ] Master **DSA basics** (Arrays, Strings, Linked Lists, Trees)
- [ ] Learn **1 programming language deeply** (Python, Java, JavaScript, C++)

#### Projects
- [ ] Build **2-3 mini projects** (Calculator, Todo App, Chat App)
- [ ] Push to GitHub with good documentation
- [ ] Host 1 project online (Netlify, Heroku, AWS)

#### Soft Skills
- [ ] Create LinkedIn profile
- [ ] Update your email address professionally
- [ ] Practice mock interviews

**Deliverables**: 3 projects on GitHub, updated LinkedIn

---

### **MONTH 3-4: Skill Enhancement** 

#### Technical Skills
- [ ] Complete **DSA intermediate** (Stacks, Queues, Graphs, Dynamic Programming)
- [ ] Master **1 framework** (React, Express, Django, Flutter, etc.)
- [ ] Start **system design basics**

#### Projects
- [ ] Build **2-3 substantial projects** using your chosen framework
- [ ] Include features: Authentication, Database, API Integration
- [ ] Host projects on GitHub with README, demo videos

#### Networking
- [ ] Join **college tech communities**
- [ ] Attend **tech talks and webinars**
- [ ] Follow companies you want to intern at

**Deliverables**: 5-6 quality projects, active GitHub profile

---

### **MONTH 5-6: Application Season Begins** ⭐

#### Resume Building
- [ ] Create **1-page resume** (concise, impactful)
- [ ] Highlight: Skills, Projects, Achievements
- [ ] Add: LinkedIn URL, GitHub profile, Portfolio

#### Start Applying
- [ ] Apply to **10-15 companies** per week
- [ ] Target: Startups, Normal MNCs, Top MNCs
- [ ] Use platforms: LinkedIn, AngelList, Internshala, HackerEarth, company websites

#### Interview Prep Begins
- [ ] Start **coding practice** (LeetCode, HackerRank)
- [ ] Solve **20-30 DSA problems** (Easy & Medium)
- [ ] Prepare **2-minute introduction**

**Deliverables**: Resume ready, 50+ applications sent

---

### **MONTH 7-8: Interview Season** 🎤

#### Intensive Preparation
- [ ] Solve **50+ coding problems**
- [ ] Mock interviews 2x/week
- [ ] Study company backgrounds
- [ ] Prepare answers for: "Tell me about yourself", "Why our company?", "Your project"

#### Application Tracking
- [ ] Track all applications (Create spreadsheet)
- [ ] Follow up with recruiters
- [ ] Attend **online/offline recruitment drives**

#### First Internship Secured 🎉
- [ ] Get interview calls
- [ ] Clear technical + HR rounds
- [ ] Negotiate stipend if possible

**Deliverables**: First internship offer (or keep applying)

---

### **MONTH 9-12: Internship Phase 1** 💼

#### During Internship
- [ ] Learn deeply about tech stack
- [ ] Contribute meaningfully to projects
- [ ] Build relationships with mentors
- [ ] Document your learnings
- [ ] Ask for feedback regularly

#### Parallel Activities (if time permits)
- [ ] Continue DSA practice
- [ ] Build a side project
- [ ] Network with other interns

#### Post-Internship
- [ ] Get **letter of recommendation**
- [ ] Update resume with internship achievements
- [ ] Optional: Apply for 2nd internship (if time available)

**Deliverables**: Internship completion, LOR, updated resume

---

### **MONTH 13-14: Second Round (Optional but Recommended)**

#### Why 2nd Internship?
- Stronger resume for placements
- Different tech stack experience
- More networking

#### Strategy
- Apply to different companies
- Choose different domain/technology
- Repeat interview prep process

**Deliverables**: 2nd internship offer (optional)

---

### **MONTH 15+: Final Year - Placement Ready** 🎯

#### Pre-Placement
- [ ] Update resume with both internships
- [ ] Prepare stories from internship experiences
- [ ] Strong GitHub profile with 8-10 projects
- [ ] 100+ DSA problems solved

#### Placement Drive
- [ ] Attend all recruitment drives
- [ ] Apply to dream companies

- [ ] Negotiate offer

## 🎤 Interview Preparation

### Round 1: Online Assessment
- **Duration**: 1-2 hours
- **Format**: MCQs + Coding Problems
- **Topics**: DSA, Aptitude, Logical Reasoning
- **Prep**: Solve 50+ problems on LeetCode

### Round 2: Technical Interview
- **Duration**: 45-60 minutes
- **Format**: 1-2 coding problems + Discussion
- **Topics**: DSA, Problem-Solving, Code Quality
- **Tips**:
  - Think out loud
  - Discuss approach before coding
  - Write clean, readable code
  - Test with examples

### Round 3: HR Interview
- **Duration**: 15-30 minutes
- **Questions**:
  - Tell me about yourself
  - Why do you want to join us?
  - What are your strengths & weaknesses?
  - Where do you see yourself in 5 years?
  - Any questions for us?
- **Tips**:
  - Be genuine
  - Research company culture
  - Show enthusiasm

### Interview Resources
- **Coding Practice**: LeetCode, HackerRank, CodeChef
- **System Design**: Grokking System Design, YouTube channels
- **Behavioral**: STAR method for answers
- **Mock Interviews**: Pramp, Interviewing.io

## 💡 Tips & Tricks

### Resume Tips
✅ **Do:**
- Keep it 1 page
- Use action verbs (Built, Developed, Implemented)
- Quantify achievements (30% faster, 1000+ users)
- Highlight relevant skills
- Include GitHub & Portfolio links

❌ **Don't:**
- Use fancy fonts or colors
- Include irrelevant information
- Make spelling mistakes
- Leave gaps unexplained

### GitHub Profile Tips
✅ **Do:**
- Write detailed README for projects
- Use meaningful commit messages
- Pin 3-4 best projects
- Keep consistent contribution history
- Add project demo links & screenshots

❌ **Don't:**
- Have empty repositories
- Copy-paste code from tutorials
- Leave projects unfinished
- Use bad naming conventions

### Interview Tips
✅ **Do:**
- Practice speaking and coding simultaneously
- Solve problems step-by-step
- Ask clarifying questions
- Test your code
- Explain your thought process
- Be honest about weaknesses

❌ **Don't:**
- Jump into coding immediately
- Write messy code
- Use unclear variable names
- Panic if you don't know the answer
- Lie about your skills

### Application Tips
✅ **Do:**
- Apply consistently (10-15/week)
- Personalize cover letters for top companies
- Follow up after 1 week if no response
- Track all applications
- Learn from rejections

❌ **Don't:**
- Apply to only 1-2 companies
- Use generic cover letters
- Expect immediate responses
- Give up after first rejection
- Ignore feedback

### Networking Tips
✅ **Do:**
- Connect with alumni working in companies
- Join LinkedIn & tech communities
- Attend webinars & tech talks
- Engage with company social media
- Thank interviewers with personalized messages

❌ **Don't:**
- Connect without a personalized message
- Ignore follow-ups
- Be passive on social media
- Underestimate smaller networks
